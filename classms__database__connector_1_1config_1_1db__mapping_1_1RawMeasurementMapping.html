Detailed Description

Raw measurement mapping allowing None values for unfilled templates.

Similar to MeasurementMapping but allows None values to represent unfilled template entries. Used to store partial/incomplete mappings before they are validated and filled in.

Example structure with unfilled entry: {"path.to.field": "field", "path.to.unknown": null}
