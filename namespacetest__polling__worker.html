test_polling_worker.build_worker (   mocker)

Create a configurable PollingWorker test context.

This fixture returns a builder function so each test can override only the dependency that matters for the scenario under test.

Sentinel behavior:

  • ... means "use the fixture default".
  • None means "explicitly missing/unavailable" (used for negative paths).

The returned object is a SimpleNamespace with the worker and all relevant mocks/providers for assertions.
