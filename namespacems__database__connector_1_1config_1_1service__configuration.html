ServiceConfiguration ms_database_connector.config.service_configuration.load_configuration ( str  configuration_file)

Load and validate the service configuration from a JSON file.

Reads the configuration file specified by the path parameter, validates it against the ServiceConfiguration schema, and returns the parsed object.

Parameters

Returns
ServiceConfiguration The validated configuration object.
Exceptions
