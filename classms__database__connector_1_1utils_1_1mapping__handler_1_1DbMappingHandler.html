Detailed Description

Load, validate, and manage AIMC-to-InfluxDB field mappings.

Maintains mapping in memory and optionally persists updates to disk. Supports both full validated mappings and partial templates with null values. Invalid mapping files are logged and ignored to allow manual correction.

       (None for partial templates).
